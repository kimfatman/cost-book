# 算得清 · 商家成本管家

面向**中小商家**的精细化成本核算小程序高保真交互原型。以餐饮门店为演示场景，覆盖成本记账、菜品成本核算、成本构成分析、月度报表与供应商管理全链路。

> 本项目为**纯静态原型**：原生 HTML/CSS/JS、零第三方依赖、双击 `index.html` 即可离线运行。数据全部来自本地模拟数据（`mock.js`），接口经由 API 桩层（`api.js`）调用，后续可无缝替换为真实后端。

---

## 功能一览

| 模块 | 说明 |
|---|---|
| 工作台 | 店铺概览、7 月预算进度、收入/毛利/成本率 KPI、近 6 月趋势、待办提醒、快捷入口 |
| 记账 | 按日分组的成本流水、支出/收入切换、分类与关键词筛选、悬浮记一笔 |
| 记一笔 | 类型切换、金额校验、分类单选、日期面板、凭证动作面板（模拟拍照/相册）、编辑复用 |
| 成本分析 | 本月/上月成本构成环形图、趋势柱状图、TOP5 高成本菜品、供应商支出排行 |
| 菜品成本 | 菜品列表（搜索/分类筛选）、成本详情（毛利率环 + 用料配方 BOM 增删重算 + 单位成本趋势） |
| 成本报表 | 月度报表列表、报表详情（成本明细表 + 毛利统计表 + 导出交互） |
| 供应商 | 分组列表、搜索、新增/编辑/删除（二次确认）、拨打电话模拟 |
| 分类管理 | 成本分类增删改查、颜色选择、删除占用校验 |
| 我的 | 店铺卡、经营工具入口、提醒开关、关于弹窗 |

## 技术栈

- **运行时**：原生 HTML + CSS + JavaScript（ES5 语法，兼容性优先），无框架、无构建
- **图标**：58 个 Lucide 内联 SVG（`icons.js` 自动注入），完全离线
- **图表**：手写内联 SVG（环形图/柱状图）+ CSS 动画，无图表库
- **路由**：自研轻量页面栈（Tab 切换 + 子页 push/pop + 滑动动效）
- **数据层**：`mock.js` 单一数据源 + `api.js` 异步桩层（模拟网络延迟，标注真实接口替换点）

## 快速开始

### 本地预览（任选其一）

```bash
# 方式一：直接双击 index.html（Chrome/Edge 即可，完全离线）
# 方式二：本地静态服务器
python -m http.server 8618 --directory cost-book-mini
# 打开 http://localhost:8618/
```

### 体验建议路径

```
工作台 → 记一笔（保存） → 记账列表刷新 → 分析页构成变化 → 菜品成本 → 详情编辑配方
```

## 目录结构

```
cost-book-mini/
├── index.html          # 应用外壳（状态栏/导航栏/11 屏/TabBar/FAB/全局交互层）
├── styles.css          # 设计令牌 + 全套组件样式 + 动效 + 暖纸噪点氛围
├── icons.js            # Lucide 内联 SVG 图标库（58 个，离线）
├── mock.js             # 单一模拟数据源（DB 对象，全部业务数据）
├── api.js              # API 桩层（16 个接口，标注真实替换点）
├── app.js              # 应用核心：路由/全局交互/4 个 Tab 屏渲染
├── subpages.js         # 子页模块：记一笔/菜品/报表/供应商/分类（7 模块）
└── docs/               # 开发与维护文档（见下方索引）
```
