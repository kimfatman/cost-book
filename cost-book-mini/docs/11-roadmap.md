## 二、Phase 1 · P1 修复（本周优先）

### 1.1 C4/C5 — 上月基数修正（数据口径兜底）
- **问题**：6 月成本率写死 58.2（实测 58.96）；上月收入基数 201,800 与报表/趋势 198,400 冲突。
- **方案**：以 `trend` 末位为事实源，重算 `month.lastRatio / prevRevenue / prevProfit / revenueDelta / profitDelta / ratioDelta`，保证环比数字全部可复核。
- **验证**：Node 断言 `ratioDelta = 60.0 − 58.96 = +1.04pp` 等全部自洽。

### 1.2 U1 — 登录协议勾选初始态
- **问题**：`#lgAgree` 视觉已勾选、逻辑 `agreed=false`，点登录必报错。
- **方案**：初始渲染为未勾选态（透明底 + 无对勾），或默认 `agreed=true` 并在点击时切换。推荐前者（更诚实）。
- **验证**：未勾选时登录提示"请先同意"；勾选后正常进入引导。

### 1.3 U2 — 周几标签错位
- **问题**：`'一二三四五六日'[getDay()]` 索引 0 是"一"，周日错位。
- **方案**：改为 `'日一二三四五六'[getDay()]`。
- **验证**：7/13（周一）显示"周一"，7/19（周日）显示"周日"。

### 1.4 U4 — 分析页分段切换联动
- **问题**：切"上月"只换环形图；趋势标题硬编码 60.0%、TOP5/供应商/隐性成本仍是本月。
- **方案（推荐）**：分段切换只作用于成本构成模块（当前设计意图），但把**趋势标题**改为动态（读 `periods.cur.ratio` / `periods.last.ratio`），并在构成模块下方加一行小字"以上为 {上月|本月} 成本构成，其余模块为当前月数据"，避免误读。
- **备选**：全模块联动（工作量大，趋势/TOP5 需补上月数据，不建议原型阶段做）。

## 三、Phase 2 · P2 修复（健壮性与一致性）

### 2.1 C6/C7 — 环比 delta 实时计算
- 报表分类 `delta`、TOP5 `delta` 从手写改为渲染时由相邻期数据实时计算（`pct` 差值 / `history` 末两位差）。
- 消除手填漂移，任何数据修改后环比自动正确。

### 2.2 C8 — BOM 数量×单价
- `submitBom`：解析 `qty` 中的数字，`amount = price × qty`；无数字时默认 1。
- `addBomItem` 的 `recalcProduct` 已统一，仅需改表单侧。

### 2.3 C9 — fresh 损耗率分母
- `lossAmt / (lossAmt + revenue)` → `lossAmt / revenue`（标准口径）。

### 2.4 U8 — 健壮性收口
- `renderShare`：`share[5]+share[6]` 改为 `share.slice(5)` 求和 + 长度防御。
- `renderAnaTop`：`maxCost = 25` 改为动态取最大值。
- `recordState.keyword` / 全部动态插值走 `esc()` 收口（含单引号）。
- `deleteBom` / 分类删除后 `share` 按名称兜底为 0 而非崩溃。

### 2.5 U6/U9/U10 — 体验微调
- 成本率 KPI 颜色语义：成本率上涨用警示色、收入/毛利上涨用品牌色。
- 凭证/导出/分享/拨号等演示交互增加"演示"角标或 toast 文案明确化。
- 日期面板提示"演示仅支持 2026-07"。

## 五、Phase 4 · 接后端（微信云开发）

> 完整方案见 `docs/07-wechat-cloud-guide.md`，此处只列执行顺序。

1. **登录链路**：手机号验证码 → `wx.cloud` 登录态 → 绑定 `openid`。
2. **数据模型**：`DB` 各集合（store/records/products/categories/suppliers/reports）建表，`mock.js` 数据灌入作为种子。
3. **API 替换**：`api.js` 16 个桩函数逐条替换为云函数调用（注释已标注替换点），签名不变。
4. **隐性成本引擎迁移**：`hidden-cost.js` 逻辑迁云函数 `analysis.hiddenCost`，输入改服务端聚合数据。
5. **定时报表**：云函数定时器每月 1 日生成上月报表。
6. **凭证上传**：`form` 拍照/相册 → 云存储 → 记录 `attach` 存 fileID。
